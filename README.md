# bigpixelrocket-releases

Published builds of Bigpixelrocket, one release per build: the DMG to install, the update archive, and the feed the installed app polls.

- Dev channel: releases `dev-<N>`, where `N` is the build number. The `dev-feed` release holds the feed installed dev builds read.
- Production: releases `v<version>`, with their feed in `production-feed`. None are published yet.
